# Keyboard shortcuts

| Key               | Action                                         |
| ----------------- | ---------------------------------------------- |
| `←↑→↓`            | Move selection                                 |
| `Shift+arrows`    | Extend selection                               |
| `Cmd+A`           | Select all (in current filter)                 |
| `Esc`             | Clear selection / close loupe                  |
| `Space` / `Enter` | Open loupe on selected                         |
| `6 7 8 9`         | Color label red / yellow / green / blue        |
| `5`               | Color label purple                             |
| `0`               | Clear color label                              |
| `T`               | Add keyword (focus tag input)                  |
| `Cmd+K`           | Command palette                                |
| `Cmd+F`           | Focus search                                   |
| `1 2 3 4`         | Layout: justified / grid / masonry / filmstrip |
| `Y`               | Layout: timeline                               |
| `[` `]`           | Timeline: coarser / finer groups (year–day)    |
| `-` `=`           | Thumb size down / up                           |
| `S`               | Show similar to selected                       |
| `D`               | Show duplicates of selected                    |
| `Cmd+,`           | Settings                                       |
